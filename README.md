## The line

Hi, you've reached Mittens. I'm busy knocking things off the table. Leave a message after the purr — I'll ignore it.

## Run it

```sh
python3 main.py
```

Running it prints the greeting and writes it to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
